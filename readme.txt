== Installation ==

**Automatic Installation (Easiest)**

1. Go to your WordPress dashboard
2. Navigate to Plugins → Add New
3. Search for "Giant Checkout Offers for WooCommerce"
4. Click "Install Now" and then "Activate"
5. Make sure WooCommerce is installed and active

**Manual Installation**

1. Download the plugin ZIP file
2. Go to Plugins → Add New → Upload Plugin
3. Choose the ZIP file and click "Install Now"
4. Activate the plugin
5. WooCommerce must be active for bumps to appear

**After Installation**

1. Go to **WooCommerce → Giant Checkout Offers** in your admin menu
2. Click "Create Your First Bump"
3. Choose a product to offer, set a discount, pick a position and template
4. Customize the design to match your store
5. Set the status to Active and you're live

== Frequently Asked Questions ==

= Will this work with my theme? =

Yes. Giant Checkout Offers for WooCommerce injects bumps using standard WooCommerce hooks, so it works with any properly built WooCommerce theme — Astra, Kadence, Storefront, OceanWP, and custom themes included.

= Can I show different bumps to different customers? =

Absolutely. You can target each bump based on what's in the customer's cart — by specific products, product categories, or tags. A customer buying a camera can see a camera bag offer while someone buying a book sees something completely different.

= Does it support variable products? =

Yes. Variable products work perfectly as bump offers. The variation selector (size, color, etc.) appears directly inside the bump, so customers can choose the exact option they want without going anywhere else.

= Will the bump slow down my checkout page? =

Not at all. Bumps are loaded efficiently and added to the cart via AJAX — no page reloads, no impact on checkout speed. We care about performance.

= What happens if the customer already has the bump product in their cart? =

The bump won't show. We check for this automatically so customers never see an offer for something they've already added.

= Can I have more than one active bump? =

Yes! You can create as many bumps as you need. Giant Checkout Offers for WooCommerce will determine which bump to show based on the targeting rules you've set for each one.

= Is it compatible with WooCommerce HPOS? =

Yes. Giant Checkout Offers for WooCommerce is fully compatible with WooCommerce High-Performance Order Storage (HPOS / Custom Order Tables).

= What is the AI Engine in the Pro version? =

The AI Engine analyzes your products and bumps, then automatically picks the best bump to show for each customer's cart. You run the analysis once, and it updates automatically whenever you add new products. It's like having a conversion expert working for you 24/7.

= What does the Analytics dashboard show? =

The Pro Analytics dashboard shows impressions (how many times a bump was seen), conversions (how many times it was accepted), conversion rate, and total revenue generated — for each individual bump and for your store overall. You can filter by the last 7, 30, or 90 days.

= Can I translate it to my language? =

Yes. Giant Checkout Offers for WooCommerce is fully translation-ready. It works with WPML, Polylang, and any standard WordPress translation plugin.

= What if I need help? =

Check our documentation at giantwpsolutions.com, or post in the WordPress.org support forum. Pro users get priority support with faster response times.

== External Services ==

**The free version of this plugin does not connect to any external services.**

The Pro version uses one external API for the AI Engine feature, disclosed in full below.

= Anthropic AI API (Pro — AI Engine only) =

The AI Engine feature in Giant Checkout Offers Pro sends data to Anthropic's AI API to analyze your product catalog and automatically recommend which order bump to show for each product.

**Service:** Anthropic (anthropic.com)
**API endpoint used:** https://api.anthropic.com/v1/messages

**What data is sent:**

* Product IDs, names, prices, and category names
* Product descriptions — plain text only, trimmed to 200 characters per product
* Bump names, associated product names, and discount configurations (percentage or fixed amount)

**What is NOT sent:**

* No customer names, emails, addresses, or payment information
* No order history or transaction data
* No personal or identifiable information of any kind

**Why it is sent:**

The data is used to generate a product-to-bump recommendation map using AI analysis of product relationships. The recommendation result is stored entirely on your own server. Anthropic does not retain store data beyond the scope of processing the request.

**When the API is called:**

* When a store administrator manually clicks "Analyze Products" in WooCommerce → Giant Checkout Offers → AI Engine settings
* Automatically (one time) when a new product is published, if AI mode is active
