== Installation ==

**Automatic Installation (Recommended)**

1. Go to your WordPress dashboard
2. Navigate to Plugins → Add New
3. Search for "Giant Checkout Offers for WooCommerce"
4. Click "Install Now" and then "Activate"
5. Ensure WooCommerce is installed and active

**Manual Installation**

1. Download the plugin ZIP file
2. Go to Plugins → Add New → Upload Plugin
3. Upload the ZIP file and click "Install Now"
4. Activate the plugin
5. WooCommerce must be active for order bumps to appear

**After Installation**

1. Go to **WooCommerce → Giant Checkout Offers** in your WordPress admin menu
2. Click "Create Your First Bump"
3. Choose an offer product, set a discount, select a position and template
4. Customize the design to match your store's branding
5. Set the status to Active — your first WooCommerce order bump is live

== Frequently Asked Questions ==

= Will this WooCommerce order bump plugin work with my theme? =

Yes. Giant Checkout Offers injects order bumps using standard WooCommerce hooks, so it works with any properly built WooCommerce theme — including Astra, Kadence, Storefront, OceanWP, GeneratePress, and custom themes.

= Can I show different checkout offers to different customers? =

Absolutely. You can target each order bump based on what's in the customer's cart — by specific products, product categories, or tags. A customer buying a camera sees a camera bag offer; a customer buying a book sees something completely different. Smart conditional targeting out of the box.

= Does this WooCommerce upsell plugin support variable products? =

Yes. Variable products work perfectly as order bump offers. The variation selector (size, color, etc.) appears directly inside the bump — no extra popups or redirects needed.

= Will the order bump slow down my WooCommerce checkout page? =

Not at all. Order bumps are loaded efficiently and added to the cart via AJAX — no page reloads, no impact on checkout speed or performance.

= What happens if a customer already has the bump product in their cart? =

The bump won't show. We automatically detect this so customers never see a checkout offer for something they've already added.

= Can I run more than one active order bump? =

Yes. Create as many order bumps as you need. Giant Checkout Offers determines which bump to show based on the targeting rules you've configured for each one.

= Is this plugin compatible with WooCommerce HPOS? =

Yes. Giant Checkout Offers is fully compatible with WooCommerce High-Performance Order Storage (HPOS / Custom Order Tables).

= What does the AI Engine in the Pro version do? =

The AI Engine analyzes your product catalog and all active order bumps, then automatically selects the best bump to display for each customer's cart. Run the analysis once — it updates automatically whenever you add new products. It's like having a conversion optimization expert working for you 24/7.

= What does the Pro Analytics dashboard show? =

The Pro Analytics dashboard tracks impressions (how many times a bump was seen), conversions (how many times it was accepted), conversion rate, and total revenue — for each individual bump and for your store overall. Filter by the last 7, 30, or 90 days.

= Can I translate it into my language? =

Yes. Giant Checkout Offers is fully translation-ready and works with WPML, Polylang, and any standard WordPress translation plugin. RTL languages are also fully supported.

= Where can I get help with the plugin? =

Check our documentation at giantwpsolutions.com, or post in the WordPress.org support forum. Pro users receive priority support with faster response times.

== External Services ==

**The free version of this plugin does not connect to any external services.**

The Pro version uses one external API for the AI Engine feature, disclosed in full below.

= Anthropic AI API (Pro — AI Engine Only) =

The AI Engine feature in Giant Checkout Offers Pro sends data to Anthropic's AI API to analyze your product catalog and automatically recommend which order bump to show for each product.

**Service:** Anthropic (anthropic.com)
**API endpoint used:** https://api.anthropic.com/v1/messages

**What data is sent:**

* Product IDs, names, prices, and category names
* Product descriptions — plain text only, trimmed to 200 characters per product
* Bump names, associated product names, and discount configurations (percentage or fixed amount)

**What is NOT sent:**

* No customer names, emails, addresses, or payment information
* No order history or transaction data
* No personal or identifiable information of any kind

**Why it is sent:**

The data is used to generate a product-to-bump recommendation map using AI analysis of product relationships. The recommendation result is stored entirely on your own server. Anthropic does not retain store data beyond the scope of processing the request.

**When the API is called:**

* When a store administrator manually clicks "Analyze Products" in WooCommerce → Giant Checkout Offers → AI Engine settings
* Automatically (one time) when a new product is published, if AI mode is active
